# Licence provenance

This repository is MIT-licensed (see `LICENSE`).

The project began as a fork of
[mrishab/google-photos-delete-tool](https://github.com/mrishab/google-photos-delete-tool),
which publishes no licence file. The v3 codebase (engine, DOM adapter,
selector pack, licence layer, diagnostics, tests, build system, docs) is a
rewrite made for this repository, and the MIT grant covers that code. What
remains from the original is the idea of automating the Google Photos UI, which
copyright does not cover, and the look of the floating panel. The original
author is credited in the README and git history.

To extend commercial use beyond the current scope, get explicit permission
from the upstream author or replace the remaining panel styling.
